# المرحلة 2 — الحضور، المدفوعات، تفاصيل الطالب، محتوى الحصص، لوحة الصف

بناءً على ملفات المواصفات الأربعة وقرارك: نطاق هذه المرحلة هو **المرحلة 2 فقط**، والفيديوهات عبر **روابط يوتيوب** (بدون رفع فيديو داخل المنصة). الامتحانات والسنتر والباقات مراحل لاحقة.

## 1. الجداول الجديدة (مع RLS وGRANTs)

| الجدول | الحقول الأساسية | من يقرأ | من يكتب |
|---|---|---|---|
| `attendance` | id, lesson_id, student_id, teacher_id, status (present/absent), note | المدرس المالك + الطالب صاحب السجل | المدرس المالك فقط |
| `payments` | id, student_id, teacher_id, year, month, amount, paid (bool), paid_at, note | المدرس المالك + الطالب صاحب السجل | المدرس المالك فقط |
| `lesson_content` | id, lesson_id, teacher_id, type (video/image/file/link/text), title, url, body, file_size, sort_order | المدرس المالك + طلاب الصف المسجّلون | المدرس المالك فقط |
| `class_posts` | id, class_id, teacher_id, type (announcement/video/image/file/link/text), title, body, url | المدرس المالك + طلاب الصف المسجّلون | المدرس المالك فقط |

- `payments`: قيد فريد (student_id, year, month) حتى لا تختلط بيانات شهر بآخر.
- `attendance`: قيد فريد (lesson_id, student_id).
- سلة تخزين خاصة جديدة `lesson-files` للصور والملفات (PDF)، وقراءتها مقيدة بأعضاء الصف عبر سياسات التخزين على مسار المدرس.
- تفعيل Realtime على `class_posts` و`lesson_content` و`payments` و`attendance`.

## 2. شاشات المدرس الجديدة/المحدّثة

- **الحضور**: فتح حصة → قائمة طلاب الصف بتحديد حاضر/غائب لكل واحد، حفظ جماعي، مع سجل تلقائي.
- **المدفوعات**: اختيار السنة والشهر → جدول كل الطلاب (مدفوع أخضر / غير مدفوع أحمر) + المبلغ وتاريخ الدفع + إجمالي الشهر في بطاقة.
- **قائمة الطلاب محدّثة**: بحث، جدول بالأعمدة (الاسم، الصف، الهاتف، الحالة، الحضور، الغياب، المدفوعات، إجراءات) وفق ملف الشاشات.
- **تفاصيل الطالب**: بطاقة علوية + تبويبات (المدفوعات، الحضور والغياب، الملف الشخصي)؛ تبويب الحضور فيه مؤشر دائري بالنسبة و3 أرقام (إجمالي الحصص/حضور/غياب) وجدول السجل. تبويبا النتائج والامتحانات مكان محجوز "قريبًا" لحين مرحلة الامتحانات.
- **محتوى الحصة**: اختيار الصف ثم الحصة، قائمة جانبية بالأنواع، بطاقات العناصر (أيقونة النوع، الاسم، حجم الملف، تعديل/حذف). الفيديو = رابط يوتيوب يُعرض داخل مشغّل مضمّن؛ الصور والملفات تُرفع للتخزين.
- **لوحة الصف**: نشر إعلان/فيديو/صورة/ملف/رابط/شرح، تظهر للطلاب لحظيًا.

## 3. شاشات الطالب الجديدة/المحدّثة

- الحصص: فتح الحصة لعرض محتواها (فيديو يوتيوب مضمّن، صور، ملفات للتحميل، روابط، شرح).
- لوحة الصف: عرض المنشورات (قراءة فقط).
- الحضور: نسبته وسجله (قراءة فقط).
- المدفوعات: حالته الشهرية (قراءة فقط).

## 4. تحديث القائمة الجانبية للمدرس

الرئيسية، الطلاب، المحتوى، الحصص، الحضور، المدفوعات، لوحة الصف، الصفوف، ملفي — مع إبقاء مكان "الامتحانات" للمرحلة القادمة.

## 5. ملاحظات تقنية

- كل القراءات/الكتابات عبر RLS (لا حماية بالواجهة فقط) — الطالب لا يستطيع تعديل حضوره أو مدفوعاته ولا رؤية زملائه حتى بطلب مباشر.
- بعد الهجرة يُعاد توليد أنواع TypeScript ثم بناء الصفحات، وأخيرًا فحص البناء وتجربة التدفق كاملًا في المعاينة (إضافة حضور، دفعة شهرية، محتوى حصة، منشور لوحة).
